# Firehouse BOGO watch

**🚨 Open the app: [brycekuhn.github.io/BOGOwatch](https://brycekuhn.github.io/BOGOwatch/)**

One question, answered the moment you open it: is there a Firehouse Subs buy-one-get-one deal today?

## The deal

Firehouse Subs Canada offers a BOGO the day after one of these teams wins:

| Team | Promo code |
| --- | --- |
| Ottawa Senators | `SENSWIN` |
| Toronto Maple Leafs | `LEAFSWIN` |
| Edmonton Oilers | `OILERSWIN` |
| Calgary Flames | `FLAMESWIN` |

The app assumes the BOGO is good the day after a win and that overtime and shootout wins count. Those are assumptions, not confirmed terms, so check the Offers tab in the Firehouse Subs app before you order.

## What it shows

- 🚨 Yes, 🚫 No, or ⏳ Maybe (last night’s result isn’t in yet).
- On a BOGO day: every winning team’s code with a Copy button, plus links to the Firehouse app, firehousesubs.ca, and a Share button.
- Tonight’s games, the next chance at a BOGO, and the season so far.
- A season calendar. Tap a day to see its games.
- A savings tracker in CAD, stored only on your device.
- Team themes. Auto, the default, uses the winning team’s colours on a BOGO day and the Firehouse look otherwise.
- Switches for which teams count. The Canucks, Jets and Canadiens are there too, but they’re off by default because they aren’t part of the deal.

## Add it to your home screen

- **iPhone:** open the link in Safari, tap Share, then Add to Home Screen.
- **Android:** open the link in Chrome, tap the ⋮ menu, then Add to Home screen or Install app.

## How it stays up to date

A GitHub Action ([`update-scores.yml`](.github/workflows/update-scores.yml)) runs [`update-scores.mjs`](update-scores.mjs), which pulls the regular-season schedule and final scores for all seven Canadian teams from the NHL’s public web API. When the results change, it commits a new [`data.json`](data.json) and redeploys the site to GitHub Pages.

It’s scheduled every 30 minutes on game nights (about 7 PM to 4 AM Eastern) and once at noon. GitHub often starts scheduled runs late or skips them, so a late game’s result can take a while to show up. The page lets you tap who won in the meantime.

The page reloads its data every 10 minutes and whenever you come back to it.

## Changing a promo code

Edit [`codes.json`](codes.json) on GitHub and commit to `main`. That redeploys the site automatically. Codes can use capital letters, numbers and dashes, up to 24 characters.

## Files

| File | What it is |
| --- | --- |
| `index.html` | The whole app: HTML, CSS and JavaScript, no build step |
| `update-scores.mjs` | Node 20 script that fetches NHL scores and writes `data.json` |
| `.github/workflows/update-scores.yml` | Runs the script on a schedule and deploys to Pages |
| `data.json` | Schedule and scores, generated by the Action (don’t hand-edit) |
| `codes.json` | Team name → promo code |
| `manifest.webmanifest`, `sw.js`, icons | Home-screen install and offline support |

## Running it locally

```bash
node update-scores.mjs
python3 -m http.server 8000
```

Then open http://localhost:8000/. The first command needs network access to `api-web.nhle.com`.
